Pick a mission

Three mission profiles

Choose one now. You’ll carry the same profile into the Scribe’s Arsenal and use its tools in the matching exercise.

Packet Analyst

Prepare tools for examining a provided packet capture and identifying protocols and conversations.

Example packages: wireshark, tshark

Network Mapper

Prepare Nmap for discovery and service identification against the explicitly designated Red Sands lab target.

Example package: nmap

Web Analyst

Prepare basic tools for inspecting an authorized training web application.

Example package: curl. Burp Suite Community Edition ships with Kali.

Mission package worksheet →

Your challenge

  1. Choose a mission and identify the tools it requires.
  2. Review the provided Kali package list. Preserve the existing base configuration.
  3. Add or remove mission packages in the profile, with facilitator guidance.
  4. If time and build capacity permit, build a custom Live ISO. Otherwise, inspect the reference profile and follow the build demonstration.
  5. Boot the resulting ISO in a disposable VM and verify that the selected tools are available.
  6. Take your mission profile to the Scribe’s Arsenal and use the tools in the matching exercise.
Safety: Only scan and test explicitly authorized Red Sands lab targets. Never bridge vulnerable lab VMs to hotel Wi-Fi. Writing an ISO to a USB erases the selected destination drive; use a spare USB only.
