Linux & Kali Foundations

New to the command line? Start here. You don’t need to memorize anything, the goal is to get comfortable looking around a system, reading what it tells you, and finding help when you’re stuck.

What is Kali, in a sentence?

Kali Linux is a version of Linux put together for security work. It’s ordinary Linux underneath, with a large collection of testing tools already installed. Everything on this page is plain Linux and works the same way anywhere.

How to read a command. Almost every command follows the same shape: the command itself, some optional flags that change how it behaves, and an argument saying what to act on.

Navigate & manage files

pwd
ls -lah
cd /etc
cd ~
mkdir -p ~/red-sands/notes
touch ~/red-sands/notes/session.txt

pwd = where am I · ls = what’s here · cd = go somewhere · mkdir = make a folder · touch = make an empty file.

Identity & permissions

whoami
id
ls -l
sudo -l

See your account, your groups, and who owns a file. Use sudo only when you truly need to, and never change permissions on system files to “see what happens.”

Processes & storage

ps aux
uptime
df -h
free -h

What’s running, how busy the machine is, and how much disk and memory are free.

Network awareness

ip -br address
ip route
ss -tulpn

Inspect your own interfaces, routes, and listening ports. This is looking at yourself. It is not permission to scan anyone else.

When you’re stuck

man ls          # the full manual for a command
ls --help       # a quick summary of options
apropos permissions   # find commands related to a word

Reading a command’s help before you run it, especially with sudo, is the single best habit you can build today.
