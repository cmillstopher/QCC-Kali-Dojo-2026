Hints

work through them in order
1

Start with recon recon

You can’t capture what you haven’t found. The web server isn’t on port 80, and a default scan won’t show it. Scan the range 8500–8600 with service/version detection — that pins the HTTP service you need, fast. (A full all-ports scan works too, but be patient and let it finish.)

2

Find the application enumerate

That service is WordPress. The flag isn’t in a blog post, the media library, or the admin area — it’s a raw image file sitting in the site’s uploads folder on disk. You reach it by typing its URL path in the address bar, not by clicking around the site.

3

Browse the files directly web

WordPress keeps uploads at a standard path. In the address bar, take the site’s base URL and add /wp-content/uploads/ onto it. Directory listing (auto-indexing) is left on, so the server shows you the folder’s contents instead of a web page — now you can click down through the folders.

4

Open the folder warmer

Inside uploads there’s a single dated folder — click into it, then into the month inside. One image there won’t look like ordinary media: that’s your King of Diamonds.

★

Claim it

The card is a plain image — just download it. That’s your flag. Stuck on the last step? Ask a volunteer for a nudge.
