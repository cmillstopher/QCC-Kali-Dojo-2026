Mission I · Packet Analyst

Read a capture off the wire

Open a packet capture and find who talked to whom and what crossed in the clear.

Your tools

wiresharkGraphical packet analysis, filters, Follow TCP Stream, Export Objects.
tsharkThe command-line version of Wireshark, for quick field extraction.

Bake them into your ISO (the Forge way)

Add the tools to your live-build package list, then build as shown at the Forge:

echo "wireshark" >> kali-config/variant-default/package-lists/kali.list.chroot
echo "tshark"    >> kali-config/variant-default/package-lists/kali.list.chroot
sudo ./build.sh --verbose      # produces your custom Live ISO

Or add them to a running Kali

sudo apt update && sudo apt install -y wireshark tshark

Verify, then go

tshark --version
wireshark --version
Go to Mission I → Wireshark reference Boot & test your ISO

Mission II · Network Mapper

Map one lab target

Run a focused scan against one authorized lab box and read back its services.

Your tools

nmapHost and service discovery; -sV for versions, -sC for default scripts.
smbmap / enum4linux-ngGoing further: list SMB shares and see what each one allows.
niktoGoing further: a quick web-server misconfig scan once Nmap finds a web port.

Bake it into your ISO (the Forge way)

echo "nmap" >> kali-config/variant-default/package-lists/kali.list.chroot
sudo ./build.sh --verbose      # produces your custom Live ISO

Or add it to a running Kali

sudo apt update && sudo apt install -y nmap
# going further: sudo apt install -y smbmap enum4linux-ng nikto

Verify, then go

nmap --version
Scope: scan only the one lab target you pick on the Arsenal page. Keep timing at -T3 or lower, the boxes are shared.
Go to Mission II → Nmap & NSE reference Boot & test your ISO

Mission III · Web Analyst

Inspect a web app by hand

Read a training app’s responses with curl, then watch the same traffic in Burp.

Your tools

curlFetch headers and bodies from the command line; route through a proxy with -x.
burpsuiteIntercepting proxy. Community Edition ships with Kali, no Pro needed. Proxy listens on 127.0.0.1:8080.
whatwebFingerprint the app and its stack in one shot.
niktoGoing further: a fast server-misconfiguration scan.
gobusterGoing further: discover hidden paths and files from a wordlist.
wafw00fGoing further: detect whether a filter/WAF sits in front of the app.

Bake it into your ISO (the Forge way)

curl and Burp CE are already on a stock Kali; add curl explicitly if you trimmed your image:

echo "curl" >> kali-config/variant-default/package-lists/kali.list.chroot
sudo ./build.sh --verbose      # produces your custom Live ISO

Or add it to a running Kali

sudo apt update && sudo apt install -y curl
# going further: sudo apt install -y whatweb nikto gobuster wafw00f
# Burp Suite CE: launch it from the Kali menu (Applications → Web Analysis)

Verify, then go

curl --version
Go to Mission III → Burp Suite reference Boot & test your ISO

All missions · General Purpose

A little of everything

A compact kit that covers all three missions. Learn a few tools well rather than installing everything.

Your tools

nmapScanning and service discovery (Mission II).
wireshark / tsharkPacket analysis (Mission I).
curlWeb inspection; Burp CE already ships with Kali (Mission III).
a text editore.g. nano, vim, or Mousepad, for keeping notes and evidence.
xfce4-screenshooter / scriptScreenshot a finding and log your terminal for the write-up, both ship with Kali, see Document & Report.

Bake them into your ISO (the Forge way)

for pkg in nmap wireshark tshark curl; do
  echo "$pkg" >> kali-config/variant-default/package-lists/kali.list.chroot
done
sudo ./build.sh --verbose      # produces your custom Live ISO

Or add them to a running Kali

sudo apt update && sudo apt install -y nmap wireshark tshark curl

Verify, then go

nmap --version; tshark --version; curl --version
Go to the Arsenal → Boot & test your ISO
